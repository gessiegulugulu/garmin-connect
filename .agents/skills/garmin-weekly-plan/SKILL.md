# Garmin Weekly Plan

1. Read `memory.md`, `.agents/training-system.md`, and the existing `TRAINING_PLAN.md` if present.
2. Calculate exact local ranges: review `today - 7 days` through yesterday; plan today through `today + 6 days`.
3. Query activities for the review range. Also obtain sleep, Body Battery, stress, resting heart rate, and HRV trend sufficient to judge recovery. Prefer summaries and date ranges.
4. Reconcile split recordings from the same session. Treat Garmin exercise recognition as tentative and use `memory.md` for confirmed exercise names.
5. Summarize frequency, total time, training balance, intensity, recovery, adherence to the prior plan, and notable changes. Do not fabricate weights or completed exercises.
6. Build seven dated sessions around the user's available home/gym/pool exercises. Balance push, pull, lower body, core, aerobic work, and recovery. Use RPE and duration where loads are unknown.
7. Replace `TRAINING_PLAN.md` with the active seven-day plan using the shared format. Preserve useful completed-status context only if it falls inside the new range.
8. Write the weekly review to `history/YYYY-MM/weekly-review-YYYY-MM-DD.md`. Include the new plan rationale and any missing data.
9. Present a concise review and highlight the next scheduled session.

Favor a sustainable plan over maximizing volume. Reduce load when recovery trends are poor, and avoid scheduling the same stressed muscle groups on consecutive hard days.
